你是一个资深全栈工程师和 AI Agent 系统架构师。现在请你帮助我从零构建一个项目：Local-first Personalized Academic Paper Recommendation Agent。

项目目标：
构建一个本地优先的学术论文个性化推荐 AI Agent。用户在本地运行该项目，配置自己的 LLM API Key、Zotero API 信息和研究兴趣后，系统可以连接用户的 Zotero 文献库，从 arXiv 拉取最新论文，基于用户研究画像进行本地粗排，再调用云端 LLM 进行精排和推荐解释，最后生成每日论文推荐结果，并支持用户反馈来更新兴趣画像。

重要要求：
1. 这是一个参加 AI Agent 比赛的项目，重点不是复杂算法，而是完整的 Agent 工作流、模块化设计、可演示性和混合架构。
2. 项目必须采用 local-first 设计，不依赖开发者提供服务器。
3. 用户自己的 API Key、Zotero 信息、推荐历史、反馈数据都存储在本地。
4. 本地端负责隐私敏感数据处理、Zotero 数据读取、本地缓存、embedding、粗排和反馈记忆。
5. 云端 LLM 只负责复杂推理、精排、总结和推荐解释。

推荐技术栈：
- Python 作为核心后端和 Agent workflow 语言
- Streamlit 作为第一版本地 Web UI
- SQLite 作为本地数据库

项目核心流程：

1. 用户配置：
   - LLM API Base URL
   - LLM API Key
   - LLM Model Name
   - Zotero User ID
   - Zotero API Key
   - 用户显式研究兴趣关键词
   - arXiv 关注类别，例如 cs.AI、cs.CL、cs.LG、cs.CV

2. Profile Agent：
   - 从 Zotero 读取用户文献
   - 提取 title、abstract、tags、collections、year 等信息
   - 结合用户显式兴趣生成用户研究画像
   - 本地保存 profile

3. Collector Agent：
   - 从 arXiv 拉取最近若干天或最近 N 篇论文
   - 保存 title、abstract、authors、published date、arxiv id、categories、url

4. Ranker Agent：
   - 本地 embedding 用户 profile、Zotero paper、arXiv paper
   - 计算候选论文与用户画像的相似度
   - 过滤已推荐、已忽略、重复论文
   - 输出 Top N 候选论文

5. LLM Rerank：
   - 将 Top N 候选论文的 title + abstract + 用户画像摘要发给云端 LLM
   - 让 LLM 选择 Top 5
   - 输出结构化 JSON，包括推荐分数和推荐理由

6. Digest Agent：
   - 生成每篇论文的推荐卡片：
     - title
     - authors
     - arxiv_url
     - one_sentence_summary
     - why_recommended
     - related_user_interests
     - reading_priority
   - 生成今日推荐摘要

7. Feedback：
   - 用户可以对推荐结果标记：
     - like
     - dislike
     - save
     - not_relevant
     - already_read
   - 反馈写入本地 SQLite
   - 后续推荐时使用反馈调整权重

8. UI：
   - 配置页
   - 用户画像页
   - 今日推荐页
   - 反馈按钮
   - 运行工作流按钮
   - 历史推荐页，MVP 可简化
